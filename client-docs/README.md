# Excelr8 Dashboard – Client documentation

Full reference docs for each part of the dashboard: **what it is**, **how it works**, **business value**, and **troubleshooting**. Use these as the single source for client handoff.

| Doc | Description |
|-----|-------------|
| Newsletter (newsletter.pdf) | Weekly newsletter: curation, AI content, images, HTML |
| Post Radar (post-radar.pdf) | LinkedIn post radar: top posts, commentators, reactioners, ICP |
| Campaign Manager & Automations (campaign-manager-automations.pdf) | Campaigns from CSV, hitlist invites, auto like/comment |
| Dossiers (dossiers.pdf) | Lead research and dossier view |
| HubSpot (hubspot.pdf) | Sync leads and campaigns to HubSpot (mapping tables included) |
| Flows (flows.pdf) | **Flow diagrams** – Create In-App, Hitlist, Auto Like, HubSpot sync, Post Radar |

---

**Flow diagrams** (more visuals, less text): open **flows.pdf** in this folder.

**Folder handoff:** All references point only to files in this same folder (no external or localhost URLs). Suitable for uploading to Google Drive or similar. To regenerate PDFs from source, run `npm run docs:pdf` from the project root.
